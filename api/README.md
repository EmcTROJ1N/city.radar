# Контракт API

`openapi.yaml` — источник правды (OpenAPI 3.1). Бэкенд, фронтенд и тесты подчиняются ему, а не наоборот.
Покрыт весь API, кроме векторных тайлов (`/map/tiles`, опционально при росте объёма) и подписок (этап 2): карта, отметки, источники, каталог и фиксации, модерация, админка и секреты, аутентификация. 63 метода.

## Команды

```bash
cd api && npm install
npm run lint    # Spectral: структура, x-permission у каждого метода, ответ 401
npm run mock    # Prism на http://127.0.0.1:4010 (без префикса /api/v1)
npm run types   # типы для фронтенда -> frontend/src/shared/api/schema.d.ts
npm run docs    # статическая страница документации -> api/dist/index.html
npm run check   # lint + types
```

## Как менять контракт

1. Правите `openapi.yaml`.
2. `npm run check` — линтер и перегенерация типов.
3. `cd ../frontend && npx tsc --noEmit -p tsconfig.app.json` — компилятор показывает, что сломалось на фронтенде.
4. `npm run mock` — смотрите ответы руками или фронтендом.

## Mock-сервер

- Ответы берутся из `example` в контракте; `--dynamic` генерирует данные там, где примера нет.
- Нужный ответ принудительно: заголовок `Prefer: code=304` (или `404`, `409`, `429`).
- Prism сам проверяет запросы по схеме: неверное тело — 422/400, нет токена — 401.
- Известная особенность Prism: сообщение о нарушении попадает в HTTP-заголовок, и кириллица в нём роняет сервер.

## Правила контракта

- У каждого метода есть `x-permission` (`none`, `auth` или конкретное право).
- Ошибки — `application/problem+json` (RFC 7807).
- Названия, описания и адреса — схемы `Text` и `NonEmptyText`.
- Секреты через API не передаются.
