# 04. Фиксации на карте

**Маршрут:** `/map-objects` · **Право:** `catalog.object.manage`.

Фиксация — точка или геозона, к которой привязываются источники. Здесь создаётся то,
что потом видят пользователи на публичной карте.

## Экран

- фильтры: поиск, тип, группа, вид, активность, источник;
- карта: выбор и рисование;
- форма выбранной или новой фиксации;
- таблица всех фиксаций.

Выбор синхронизирован с адресом `?id=<guid>`.

## Создание

| Поле | Описание |
|---|---|
| Название | обязательно |
| Вид покрытия | геозона или точка |
| Геометрия | клики по карте; у точки можно ввести координаты |
| Тип объекта | необязателен; задаёт категорию |
| Группа | необязательна; влияет на фильтр карты |
| Адрес | необязательный текст |
| Источники | один или несколько |
| Активна | снятый флажок скрывает объект, история сохраняется |

Для геозоны нужно минимум 3 вершины. Если тип рассчитан на точку, а выбрана зона,
форма предупредит, но сохранить не запретит.

## Источники

- Можно привязать сразу при создании или позже.
- Системный «Сайт» в поиске не показывается — он доступен неявно через категорию.
- Если у фиксации есть тип, «Сайт» уже доступен, даже без явных привязок.

## Удаление

| Ситуация | Поведение |
|---|---|
| Наблюдений нет | фиксация удаляется |
| Наблюдения есть | `409`; снимите «Фиксация активна», чтобы скрыть объект |
| Фиксация неактивна | карточка на карте отдаёт `404` |

История важнее удаления: наблюдения ссылаются на фиксацию, поэтому она деактивируется,
а не удаляется.

## После сохранения

1. Объект появляется в `map_objects`.
2. Если задан тип, появляется категория и неявный «Сайт».
3. Объект начинает отдаваться на карте, если активен.
4. Привязанный источник может создавать по нему наблюдения.
5. Пользователь может поставить отметку.

## Типовые проблемы

| Симптом | Решение |
|---|---|
| Не сохраняется геометрия | у зоны меньше 3 вершин или не заданы координаты точки |
| Не видно на карте | снята активность, объект вне области или скрыт фильтром |
| Нельзя отметить | у фиксации не задан тип |
| Не удаляется | есть наблюдения → деактивируйте |
| Нет источника в поиске | «Сайт» скрыт намеренно; остальные проверьте по типу/включённости |
