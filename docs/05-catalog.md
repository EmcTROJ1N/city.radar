# 05. Каталог

**Маршрут:** `/catalog` · **Право:** любое из `catalog.*.manage`.

Каталог — конструктор предметной области: категории, типы объектов, группы и справочник
статусов. Новый ресурс добавляется настройкой, без релиза.

## Вкладки

| Вкладка | Что настраивает |
|---|---|
| Категории | вид ресурса: «Вода», «Прочие сети» |
| Типы объектов | класс фиксаций, геометрия |
| Группы | наборы фиксаций для фильтра карты |
| Справочник статусов | библиотека цветов, иконок и весов |

Вкладка хранится в `?tab=…`; недоступные по правам вкладки не показываются.

## Категории

Поля: название, код, иконка, порядок, активность.

- Код уникален: латинские строчные буквы, цифры, `_`.
- Вместе с категорией автоматически создаётся системный источник «Сайт».
- Переименование категории меняет имя «Сайта».
- Удалить категорию, на которую ссылаются типы, группы или статусы, нельзя (`409`).

## Типы объектов

Поля: категория, название, код, геометрия (`Точка`, `Геозона`, `Любая`).

Тип нельзя удалить, если на него ссылаются фиксации (`409`).

## Справочник статусов

Поля: название, код, категория, цвет, иконка, вес, признак позитивности.

Записи справочника — шаблоны для статусов источников. У источника могут быть свои
формулировки, но готовые удобно копировать.

> Вес используется для упорядочивания, но **не выбирает итоговый статус**.
> Побеждает самое свежее актуальное наблюдение.

## Группы

Поля: название, категория, цвет, «видна по умолчанию».

- Имя уникально без учёта регистра.
- Группа участвует в фильтре карты, есть пункт «Без группы».
- При удалении группы фиксации остаются, `group_id` становится пустым.

## Как завести новый ресурс

1. Создать категорию — появится «Сайт».
2. Добавить статусы в справочник.
3. Создать типы объектов с геометрией.
4. Создать группы, если нужны.
5. Создать источник, импортировать статусы, задать промпт и таймаут.
6. Создать фиксации и привязать источники.
7. Проверить карту и карточку.

Ни один шаг не требует пересборки.

## Ограничения

| Ограничение | Причина |
|---|---|
| Коды уникальны | стабильные идентификаторы |
| Нельзя удалить категорию/тип с ссылками | целостность данных |
| «Сайт» только с категорией | один на категорию |
| Вес не влияет на итог | итог определяется свежестью |
