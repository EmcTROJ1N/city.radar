# 03. Источники данных

**Где:** раздел «Источники». **Кому:** модератор и администратор.

Источник — откуда приходят статусы. Например, Telegram-чат жильцов или системный «Сайт»,
через который отмечают обычные пользователи.

## Что видно в списке

- название источника;
- тип: Telegram-чат, MAX-чат или «Сайт»;
- статусы;
- сколько времени статус считается актуальным;
- состояние: работает, нет сообщений или ошибка;
- когда пришло последнее сообщение.

Список можно отфильтровать по названию, типу и включённости.

## Как добавить источник

1. Нажмите **«Создать источник»**.
2. Укажите название и тип.
3. Укажите чат, из которого читать сообщения.
4. Задайте, сколько времени статус считается актуальным.
5. Напишите, какие сообщения искать.
6. Сохраните источник.
7. Добавьте статусы в его карточке.
8. Включите источник и проверьте состояние.

| Поле | Что значит |
|---|---|
| Название | как источник называется в интерфейсе |
| Тип | Telegram-чат или MAX-чат; «Сайт» создаётся автоматически, для MAX сбора пока нет |
| Чат | адрес или идентификатор чата |
| Срок актуальности | через сколько статус устареет |
| Что искать | описание сообщений, которые относятся к ресурсу |
| Статусы | варианты состояния: например «Вода есть» и «Воды нет» |

> Статусы добавляются после создания источника — в его карточке.

## Статусы

- У каждого источника свой набор статусов.
- Статус можно создать вручную или скопировать из справочника.
- У статуса есть название, цвет и иконка.
- Статус, по которому уже есть отметки, удалить нельзя.

Именно эти статусы источник может сообщить на карту.

## Системный «Сайт»

- Создаётся автоматически вместе с категорией.
- Один «Сайт» на категорию.
- Доступен всем фиксациям этой категории.
- Вручную привязывать его не нужно.
- Создать или удалить нельзя — только изменить название, срок актуальности, статусы и включённость.
- Через «Сайт» обычные пользователи ставят отметки на карте.

## Состояние источника

| Состояние | Что делать |
|---|---|
| Работает | всё в порядке |
| Нет сообщений | проверить, пишут ли в чат |
| Ошибка | проверить доступы к Telegram и сеть |

Кнопка «Обновить» перезапрашивает состояние.

## Важно

- Источник сам по себе не появляется на карте: его нужно привязать к фиксации.
- Удалить источник с историей нельзя — только выключить.
- Доступы к Telegram и настройки разбора сообщений задаёт администратор.
- Без сервиса автоматического сбора карта и ручные отметки продолжают работать.
