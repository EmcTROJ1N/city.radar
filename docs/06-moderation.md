# 06. Модерация

**Маршрут:** `/moderation` · **Право:** `moderation.queue.process`.

Модерация — фильтр доверия между автоматикой и картой: сюда попадает всё, в чём система
не уверена, а также жалобы и всплески отметок.

## Вкладки

- **Очередь** — кейсы.
- **Пакетный отзыв** — массовое снятие наблюдений (при `observation.retract`).

## Очередь

Фильтры: состояние (`Открыт`, `Принят`, `Отклонён`, `Закрыт`) и вид кейса.
По умолчанию открыты открытые кейсы. Список сам обновляется раз в 60 секунд.

Если в очереди есть открытая аномалия, показывается предупреждение о всплеске отметок.

## Виды кейсов

| Вид | Когда появляется | Что делать |
|---|---|---|
| Низкая достоверность | confidence LLM ниже порога | проверить и принять/отклонить |
| Некорректный статус | LLM вернула статус не из списка источника | выбрать правильный или отклонить |
| Фиксация не найдена | в режиме «по тексту» место не определено | выбрать фиксацию и принять |
| Некорректный ответ | не JSON, цитата не найдена, ошибка LLM | проверить и решить вручную |
| Аномалия | всплеск отметок выше порога | пометить обработанной |
| Жалоба | пользователь нажал «Пожаловаться» | проверить, при необходимости отозвать наблюдение |

Аномалия создаётся одна на всплеск; после закрытия новый всплеск создаст новый кейс.

## Карточка кейса

- вид, состояние, источник, фиксация, время;
- исходное сообщение с подсветкой цитаты;
- предложение системы: статус и confidence;
- текст жалобы;
- блок «Решение».

## Принять

- Для обычных кейсов создаётся наблюдение по предложенной или выбранной фиксации/статусу.
- Для «Фиксация не найдена» выбор фиксации обязателен.
- Для «Аномалия» и «Жалоба» кейс просто закрывается как обработанный, наблюдение не создаётся.
- Время наблюдения — время исходного сообщения, поэтому одобрение старого сообщения не делает статус свежим.

## Отклонить

Кейс закрывается без изменения статуса. Причину можно указать — она попадёт в аудит.

## Жалоба

Если жалоба указывает на наблюдение, в карточке есть кнопка «Отозвать наблюдение».
Отзыв требует причины и сразу пересчитывает статус. После этого кейс можно принять или отклонить.

## Пакетный отзыв

Фильтры: источник, автор, период. Нужен хотя бы один фильтр и причина.
Отзываются только неотозванные наблюдения, максимум 10 000 за операцию.
Действие пишется в аудит и пересчитывает затронутые фиксации.

## Ограничения

- закрытый кейс повторно обработать нельзя (`409`);
- нельзя выбрать фиксацию, не привязанную к источнику;
- нельзя выбрать статус другого источника;
- пакетный отзыв необратим через UI;
- жалобы пока без отдельного rate limit.
